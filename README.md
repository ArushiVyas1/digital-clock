# ⏰ Digital Clock with Sunset Background

A visually appealing **digital clock** built using **HTML, CSS, and JavaScript**.  
The project features a **sunset background image** and dynamically displays the **real-time clock** in the center of the screen using JavaScript’s `Date` object and DOM manipulation.

---

## 🚀 Features
- Real-time clock display using JavaScript’s `Date` object.
- Centered digital time that updates every second.
- Beautiful **sunset background image** for aesthetic appeal.
- Simple, responsive design using HTML & CSS.

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the digital clock.
- **CSS3** – Styling, layout, and background image.
- **JavaScript (ES6)** – Real-time clock logic and DOM manipulation.
